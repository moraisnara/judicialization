Regressing the 2020$\to$2024 change in adversarial filings on $\bZ$, with controls and state fixed effects, gives a precise positive coefficient and a cluster-robust effective $F=\HeadlineF$ \citep{montielolea2013}. That clears conventional weak-instrument thresholds \citep{stock2005} but sits just below the $F=104.7$ at which the $tF$ critical value returns to 1.96, so inference uses the $tF$ correction \citep{lee2022}.
